11. ধরা যাক C = a + b.Y হলো কেইন্সীয় ভোগ অপেক্ষক যেখানে C = ভোগ ব্যয়, Y = আয়, a = স্বয়ম্ভূত ভোগ ব্যয় > 0 এবং 0 < b = প্রান্তিক ভোগ প্রবণতা (MPC) < 1.
এখন A স্তম্ভের বিবৃতির সঙ্গে B স্তম্ভের বিবৃতির সঠিক জোড়া চিহ্নিত করো এবং সঠিক বিকল্পটি নির্বাচন করো :
A-স্তম্ভ:
i) বিনিয়োগ গুণক
ii) গড় ভোগ প্রবণতা
iii) কর গুণক
B-স্তম্ভ:
a) b + a/Y
b) 1 / (1 - b)
c) -b / (1 - b)
(A) (i) — (a), (ii) — (c), (iii) — (b)
(B) (i) — (b), (ii) — (a), (iii) — (c)
(C) (i) — (b), (ii) — (c), (iii) — (a)
(D) (i) — (c), (ii) — (b), (iii) — (a)
সঠিক উত্তর: (B) (i) — (b), (ii) — (a), (iii) — (c)
